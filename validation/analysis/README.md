- **Manuscript-ready drafts:** `text/`. Figures: `figures/main` (V1–V8), `figures/supplementary` (S1–S6).
  Source data: `source_data/`.
- **What not to claim:** `text/claims_check.md` and `text/claims_audit.md`.
