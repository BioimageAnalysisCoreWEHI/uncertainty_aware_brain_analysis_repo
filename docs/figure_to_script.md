# Figures and tables → scripts

Figure and table numbers follow the final revised manuscript (2026-10-10).
- **Inputs.** The scripts in `figures/` read the outputs of the analysis scripts in `validation/analysis/scripts` and `validation/independent_lsfm`, which they import directly. They need the pipeline outputs; the per-registration masks, consensus maps and full-resolution crops needed to recompute them are in the data deposit (see its `README.md`).
- **Result tables.** The essential result tables and Supplementary Tables S1–S5 are in the deposit under `shared/tables/`, and the QC-sensitivity tables under `shared/qc_sensitivity/`. All other panel data are regenerated by the scripts below.

## Supplementary Information document
`figures/make_docx.py` builds the Supplementary Information `.docx` (600 dpi figures, captions, tables) from a plain-text source. It uses only the standard library and Pillow.

## Naming note
In `validation/independent_lsfm`, "gt" in file and function names refers to the dataset authors' **published registration**. That registration is itself automated, not a manual ground truth. The released tables use "published" instead.
